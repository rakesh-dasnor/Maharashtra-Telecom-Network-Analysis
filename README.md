# Maharashtra Telecom Network Performance & QoS Intelligence System

## Project Overview
This project analyzes telecom network performance and customer complaints across Maharashtra using Python, SQL and Power BI.

The objective is to understand network quality, compare operator performance, identify common network issues and analyze customer complaint patterns.

**Dataset:** 50,000 synthetic practice records.  
**Region:** Maharashtra, India.

## Project Objectives
- Analyze download and upload speeds across telecom operators.
- Compare 4G and 5G network performance.
- Identify districts with lower network performance.
- Analyze customer complaints and call drops.
- Study complaint resolution and pending complaints.
- Present business insights through an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Pandas, Matplotlib, Seaborn
- MySQL
- SQL
- Microsoft Power BI

## Project Workflow
1. Data cleaning and preprocessing using Python.
2. Exploratory Data Analysis (EDA).
3. SQL-based business analysis using 12 questions.
4. Interactive dashboard development in Power BI.
5. Business insights and recommendations.
